storm-desk support

storm-desk is a free app for Jira Service Management. It finds new requests that look like the same incident, so the team can link them and send one update.

Get help

Open an issue in the GitHub Issues page of this repository. This is the only support channel.

Please write what you did, what you expected, and what you saw. Do not put customer names, request text, or account ids in a public issue.

This is a small free tool. We read issues when we can and do not promise a reply time.
